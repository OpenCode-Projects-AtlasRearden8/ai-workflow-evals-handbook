Keep the habit.

The canary only protects you if somebody looks at it, weekly

The ritual runs about fifteen to twenty minutes:

1. Rerun the quiz — all ten, in order, no skipping, no "restart to be fair". 2. Grade in one sitting, fresh eyes, before reading anything about old runs. 3. Log it: date and setup version in the header, scorecard kept forever. 4. Glance back two runs: the total, plus any question hit twice. Done.

Compare only when something changed (chapter 03); decide only when the comparison is done (chapter 04). Weekly is about habit — changing weeks are when the habit pays for itself.

Making it stick

  • Anchor it to something that already happens. Sunday coffee, Monday setup check, month-end — attach new habits to old ones.
  • Keep the question file where you can't forget it. Pinned note, starred file, the folder you open to start your week. The friction is remembering to begin, not the grading.
  • Use the pre-committed thresholds. When the scorecard is filled, the verdict is a lookup, not a debate — that's why chapter 04's index card exists.
  • Accept "noisy runs." Graded tired, interrupted, whatever — log it anyway with a note. A noisy logged run beats a skipped one, always.
  • Two misses and a rescue plan. Missed two weeks? No guilt spiral: run the quiz once, note “back after a break — treat last logged run as OLD, this as NEW,” and see what drifted during the silence. The system is built to forgive gaps; the only unforgivable act is letting a missed week end the habit.

Honest limits — and when to go deeper

  • Ten questions is a sample, not a survey. You're detecting gross regressions, not subtle ones. When a failure mode keeps squeaking into your notes, add a question about it — the system grows with you.
  • Human grading scales badly. Past two or three scorecards a week it tires and wobbles. That's the point to graduate to automation: my separate project prompt-regression-cli runs exactly this rerun-and-compare loop for you, using these same scorecards offline.
  • This book teaches judgment, not statistics. When you genuinely need “how much worse” in a rigorous sense — model choices, stakeholder documentation — you'll want proper eval tooling and bigger question sets. You'll be well-prepared, because you already know what the numbers are for.

The end (which is really the start)

Ten fixed questions, a three-level rubric, a comparison ritual, a pre-agreed bar. Four small habits, thirty minutes a week, that turn “I think it's fine?” into “15 last week, 16 this week, nothing red-lined — go.”

The coal miner's canary never made the mines safer by being a sophisticated instrument. It made them safer by being there, by being sensitive, and by being looked at. Yours is the same. Good luck — and score honestly. · Dylan
