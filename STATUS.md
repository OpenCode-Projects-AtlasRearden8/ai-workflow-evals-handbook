# STATUS — AI Workflow Evals Handbook

Last updated: 2026-11-06 · Maintained by Dylan Asdale / Asdale Dynamics, LLC

## What was built

A substantive beginner manual on **testing your AI setups before trusting them**, in Dylan Asdale's plain "friend would explain it" voice, published by Asdale Dynamics, LLC. It teaches four repeatable habits:

1. **Build a ten-question canary quiz** (6 workhorse + 1 red-line + 1 weak-spot + 1 messy + 1 frontier).
2. **Score answers with a 0/1/2 rubric** (fail / partial / pass; each run out of 20).
3. **Spot regressions** after updates (totals → per-question → red-line check → one-line verdict; the four failure patterns: clean win, net-zero bleed, cliff, leak).
4. **Decide when good is good enough** (default ship bar 16/20, pilot band 12–15, and a red-line-zero veto that outranks any total).

Deliberately distinct from sibling projects: `prompt-regression-cli` (an automated tool) and `when-ai-gets-it-wrong-guide` (failure stories). This repo is the tool-free, repeatable *testing habits* layer — noted in README.md.

## How to run it

```bash
# Read the manual (option A: plain files)
open docs/00-start-here.md

# Read the manual (option B: browser, offline, no install)
open site/index.html

# Grade a filled scorecard offline
python3 scripts/grade.py docs/templates/example-scorecard-1.md
python3 scripts/grade.py docs/templates/example-scorecard-1.md docs/templates/example-scorecard-2.md

# Regenerate the chapter pages (index.html is handcrafted and preserved)
python3 scripts/build_site.py

# Run this repo's self-tests
bash scripts/check.sh
```

## Known gaps

- `grade.py` grading is line-based: it expects one `Score: <0|1|2>` bullet per question (the template format). Freeform scorecards won't parse — that's by design, keeping the grader trivial.
- `site/index.html` is handcrafted and not regenerated by `build_site.py`; if you edit the design, update both the script's CSS and the index page.
- The rubric is per-task advice, not per-run statistics: ten questions detect gross regressions, not subtle ones, and there are no confidence intervals (Chapter 05 is candid about this).
- Examples are deliberately fictional (Riley's small business); the worked quiz is a *shape* to copy, not a ready-made quiz for anyone's real usage.
- Docs anchor links: manuals link between chapters by file, but GitHub-style in-page anchors aren't used — navigation is file-to-file.
